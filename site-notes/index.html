Notes on building this site.

Where the painterly aesthetic came from, how it works, and where it lives.

Inspiring from

The reference was an AI-generated reel of impasto oil paintings. Thick textured strokes, off-center compositions, the same painter's hand across very different subjects. Not imitation. Pick one technique, apply it consistently, let the texture do the work.

Design approach

One SVG filter chain runs every painterly mark on the site. feTurbulence generates fractal noise. feDisplacementMap pushes pixels along it. Two primitives, three knobs, every painterly element on the page. 

<filter id="paint">
  <feTurbulence type="fractalNoise"
    baseFrequency="0.06" numOctaves="2"
    seed="5" result="noise"/>
  <feDisplacementMap in="SourceGraphic"
    in2="noise" scale="4"/>
</filter>

Three knobs to tune. baseFrequency sets noise density. scale controls push distance. seed picks the arrangement. Same seed renders the same wobble every time. Different seed gives variation that still reads as the same hand.

The brushstroke itself sits in one CSS custom property as a data URI. Sections, hero, and footer reference it through background-image. Change the seed once, the whole page shifts. Single source of truth.

Design elements

Seal

A circle plus the letters TA in Spectral, both routed through the filter. 26 px in the nav, 30 px in the footer. At display size the wobble reads as pressed by hand, not generated.

Card frame

A single <rect> with painterly stroke. preserveAspectRatio="none" lets the frame stretch to any wrapping rectangle. vector-effect="non-scaling-stroke" keeps the stroke uniform under that stretch. Different seed per card, so frames feel like siblings, not duplicates.

Brushstroke divider

A 240-wide gradient rectangle through the same filter at higher displacement. The same data URI that draws the section endings on every page.

Thumbnail mark

Wavy line, ochre triangle, water-blue circle, X. Stronger displacement (scale=1.4) so the lines read as doodled at small size, not drawn cleanly. The only thumbnail on the index, because the project trains on Quick Draw doodles.
